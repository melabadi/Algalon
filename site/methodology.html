Evidence boundary

Four layers, four different claim strengths

Only the first layer is directly measured behavior. The result becomes less certain as it moves right.

Observed

Session behavior

Wall-clock time, AI credits, model use, tokens, tools, and phase signals.

Deterministic

Matched source delta

Retained characters only when a source-aware producer proves the same-session match.

Configured

Human assumptions

Labor rate, capacity realization, relevance, review, interaction, and entry rates.

Modeled

Economic outcome

Manual time, minutes saved, labor benefit, net value, break-even time, and ROI.

From activity to evidence

One session, one overlap-safe timeline

Algalon groups by authoritative OTel session.id, hashes public labels, and never invents repository identity.

  1. CollectCopilot sends OTLP to the loopback Collector.
  2. Scrub + commitThe Collector removes sensitive fields; FastAPI transactionally deduplicates spans into SQLite.
  3. ClassifyPlanning, research, coding, validation, and unclassified activity share one timeline.
  4. ReconcileMatching direct-turn logs refine credits, models, and token totals locally.
  5. EvaluateThe same benchmark engine calculates pessimistic, base, and optimistic branches.

Current formula

Modeled return on observed AI usage cost

The stopwatch and AI usage are observed. The without-AI duration is a scenario estimate. The output is sensitivity analysis, not causal proof.

TAI = Wengaged / 60 = Σ TAI,p

Tmanual,s = Σ Tmanual,p,s

Tsaved,s = Tmanual,s − TAI

Bs = (Tsaved,s / 60) × H × ρ

Vnet,s = Bs − CAI

Rs = ΔCgross,s / Cmanual,s

ROIs = Vnet,s / CAI

TAI
Measured AI-assisted engaged minutes, after idle beyond the configured gap is removed.
Tmanual,s
Modeled equivalent manual minutes under scenario s.
H
Configured fully loaded labor rate in USD/hour.
ρ
Capacity realization: the share of saved time assumed to become economic value. Reported at 25%, 50%, and 75% so its leverage is visible.
CAI
Observed direct-turn AI usage value, with OTel fallback.
Rs
Delivery-cost reduction, bounded at 100% and unaffected by how cheap the model is.
Interpretation: Read net value, break-even time, and delivery-cost reduction first. ROI divides by AI credit spend alone, so it rises when the same work is done with a cheaper model. Model cohorts keep mixed sessions intact and are descriptive, not per-model attribution.

Manual-time construction

Each activity phase uses evidence differently

Tool counts never create value on their own. They appear only inside explicit human-time mechanisms.

PhaseObserved evidenceManual-time mechanismFail-closed behavior
Planning Output and reasoning tokens, planning tools Relevant tokens ÷ review rate + interaction overhead Reasoning is scenario-weighted and excluded in pessimistic/base; unmatched activity becomes unclassified
Research Uncached input tokens, research tools Relevant uncached material ÷ review rate + interaction overhead Cached context is excluded
Coding Same-session retained source characters Retained characters × manual-entry fraction ÷ entry rate No matched source means zero manual coding benefit
Validation Non-overlapping tool runtime, output and reasoning tokens Observed runtime + review time + interaction overhead Tool runtime is counted once; reasoning is scenario-weighted
Unclassified Measured engaged minutes Measured time × explicit scenario multiplier Nothing is silently discarded; no activity means no modeled value

Calibration

Literature can bound assumptions. Local evidence must set them.

External studies cover different people, tasks, repositories, and tools. Algalon records whether each citation is direct support, a proxy benchmark, or context only.

1

Separate task populations

Do not pool greenfield work, bug fixes, rewrites, and research-only tasks.

2

Measure comparable work

Record manual active time by phase, task type, sample size, median, and dispersion.

3

Identify parameters independently

Token relevance and review speed enter as α/v. Label relevance and time review separately to avoid false precision.

4

Keep presets as reference

Use Custom for sensitivity. Publish a calibration only after deliberate configuration and restart.
