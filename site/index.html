Get started

    Download

    Verify & install

  3. 03

Windows PowerShell

Replace <version> with the downloaded release number. Run from your chosen repository directory.

$release = "C:\Downloads\copilot-value-dashboard-<version>.pyz"
$expected = (Get-Content "$release.sha256").Split()[0]
$actual = (Get-FileHash $release -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw "Checksum mismatch" }
python $release
macOS and Linux

Replace <version> with the downloaded release number. Run from your chosen repository directory.

release="$HOME/Downloads/copilot-value-dashboard-<version>.pyz"
(cd "$HOME/Downloads" &&
  if command -v sha256sum >/dev/null 2>&1; then
    sha256sum --check "$(basename "$release").sha256"
  else
    shasum -a 256 --check "$(basename "$release").sha256"
  fi) &&
python3 "$release"
Verify build provenance

With GitHub CLI installed, verify either downloaded format before running or extracting it:

gh attestation verify <downloaded-file> --repo melabadi/Algalon
ZIP: fresh manual installation

Verify the ZIP checksum and provenance, then extract it into a new .copilot-value directory inside the chosen repository. Use the PYZ for upgrades to existing installations.

# Windows
python .copilot-value/scripts/copilot_value.py install
# macOS or Linux
python3 .copilot-value/scripts/copilot_value.py install

A closer look

From the big picture to the evidence

One local installation collects sessions across repositories. The dashboard keeps observed AI usage separate from the assumptions behind modeled value.

Portfolio comparisons

Compare net value, break-even time, and delivery-cost reduction across Pessimistic, Base, Optimistic, and Custom scenarios.

Session drill-down

Inspect engaged time, models, tools, tokens, and AI credits. Elapsed duration stays visible without being mistaken for active work.

Prompt evidence

Review captured prompts and usage locally. Prompt-level ROI stays unavailable until its phase and retained-source evidence exists.

Session Insights

Twelve operational measurements highlight patterns worth investigating. Their thresholds are explicit triage defaults, not universal performance targets.

Named calibrations

Save assumption sets, inspect supporting sources, and test sensitivity without changing observed evidence or the worker's published presets.

Local CSV export

Export indexed sessions and prompts for your own analysis. Exports can contain sensitive prompt text and should remain private.

Behind the numbers

An estimate you can examine.

Costs and activity are observed. Time saved is modeled under explicit assumptions, not causal proof of productivity. Negative results and missing evidence remain visible.
